This is a reworked version of rh1tech's [MicroFrank](https://github.com/rh1tech/frank/tree/master/hardware/microfrank) board. I wound up stripping it down to the basically a bare PCB and reworking the layout almost from scratch. The USB Hub and several other components have been switched out to account for what JLCPCB can provide.

As the original is GPL V3, I'll license this board in particular GPL V3 as well.
